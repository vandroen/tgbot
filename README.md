\# Telegram-бот «Дедлайн-помощник»



Простой и удобный Telegram-бот для управления личными задачами и дедлайнами. Написан на Python с использованием SQLite для хранения данных.



\## Функционал

\- `/start` — приветствие и справка.

\- `/add <текст>` — добавить новую задачу (например, `/add Сдать отчет`).

\- `/list` — вывести список всех активных задач с их ID.

\- `/done <ID>` — отметить задачу выполненной (например, `/done 1`).



\## Стек технологий

\- \*\*Язык:\*\* Python 3.x

\- \*\*Библиотеки:\*\* `pyTelegramBotAPI` (telebot)

\- \*\*База данных:\*\* SQLite3 (встроенная в Python, не требует установки серверов)
